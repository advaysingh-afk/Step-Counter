STEPTRACK - NORMAL HTML VERSION

1. Extract this ZIP file.
2. Open the extracted StepTrack-Fixed folder in VS Code.
3. Open index.html.
4. Right-click inside index.html and choose "Open with Live Server".
   (If Live Server is not installed, open index.html directly in your browser.)

IMPORTANT:
- Do not run npm or npm run dev for this version.
- This is plain HTML, CSS, and JavaScript in one file.
- Step counts are manually adjusted with the buttons.
